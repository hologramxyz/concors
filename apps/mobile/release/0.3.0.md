# Concors mobile 0.3.0

Release candidate prepared from the latest `main` on November 23, 2026, for iOS and Android.
Keep the new store versions in draft until the owner requests the final review submissions.
Existing verification records describe the shipping baseline; this version bump does not
claim a new physical-device test.

## What's new

- See what your agents need and what they finished in Supervisor's Overview.
- Answer approval requests directly from Overview or Supervisor's messages.
- Find recent sessions faster when mentioning an agent in Supervisor.
- Open chat images full screen on your phone, with pinch and double-tap zoom.
- Clearer approval messages, chat navigation and mobile layouts.

## Release scope

The app remains free and connects to existing machines. Retain the current store identity,
reviewer access, privacy disclosures and store artwork. Build both platforms with the
production identity using the candidate profile, inspect the artifacts, and upload to
TestFlight and Google Play internal testing. Prepare the public release records separately;
uploading a test build does not authorize submission to public store review.
