# Concors mobile 0.4.0

Prepared November 25, 2026 from `main` at `bb2f1de989cb4adb4b610baaabaec2874e79f0f3`.
This candidate targets iOS TestFlight. A public App Store review or Google Play release is
outside this build's scope. Historical release evidence is retained; the version change does
not claim fresh physical-device acceptance.

## What's new

- The new Concors logo and updated app icon and launch screens.
- Clearer tool steps, file edits, approval requests and error messages in chats.
- Webhook trigger management and clearer labels for webhook prompts.
- A Resources view that scrolls correctly on narrow phone screens.
- AI-sharing permission requested when connecting, with a full-screen iPhone consent view.

Webhook features need a connected machine running daemon 0.20.3. Use the production identity
and candidate configuration, verify the signed IPA and its source revision, then distribute
the new build to the existing internal TestFlight group. Keep the current App Store build
and Android production release intact.
